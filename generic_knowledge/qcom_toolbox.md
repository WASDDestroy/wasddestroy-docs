# 刷机工具教程——高通工具箱

> [!warning]
> 虽然高通工具箱很好用，但是其他教程使用的刷机软件已切换到"匣"。这个教程已弃用。
> 
> 如果你使用"匣"时遇到了无法解决的问题，或者需要命令行工具，可以试试本工具。
> 
> 这个教程不提供命令行工具的指导。

## 文件列表

| 名称        | 说明                                                          |
| --------- | ----------------------------------------------------------- |
| bin       | 这是存放工具箱的二进制文件的文件夹                                           |
| boot.img  | 没什么用，千万别刷入                                                  |
| 高通工具箱.exe | 我们使用的是"高通工具箱"，不是"面具工具箱"！打开"高通工具箱"后，它会显示三次版权提示，都点击确认就可以进入主界面 |
| 面具工具箱.exe | 见上一条                                                        |
| 命令行.bat   | 打开高通工具箱的命令行界面                                               |
| 驱动运行库.bat | 如果你初次打开本工具，点击"驱动运行库.bat"安装依赖，它会打开驱动和运行库文件的蓝奏云，自行下载安装即可。     |

## 主界面

![](./media/image7.webp)

| 功能                          | 说明                                                                       |
| --------------------------- | ------------------------------------------------------------------------ |
| 存储类型                        | 不需要动，Pro GT 的存储类型识别暂无问题案例                                                |
| 发送引导                        | 进入 9008 后要做的第一件事！点击按钮后，选择从下载页下载的引导文件"xbl_s_devprg_ns.melf"并确认即可，不需要操作旁边的下拉菜单 |
| 端口                          | 有时需手动指定端口，请关注设备管理器，旁边的两个方框无需勾选                                           |
| xml 批量刷入                    | 刷写第三方系统/备份镜像/救砖包时使用                                                      |
| 刷入单个分区                      | 刷写 Root 时更常用                                                             |
| 刷入分区表/写 QCN/FastbootEnhance | 暂无用途                                                                     |
| xml 批量回读                    | 利用已有的 xml 回读生成备份文件，方便生成通用救砖包；                                            |
| 回读单个分区                      | Root 时备份原分区文件时使用                                                         |
| 回读分区表/读 QCN                 | 暂无用途                                                                     |
| 回读全分区并生成 gpt 和 xml          | 生成备份包用                                                                   |
| 擦除单个分区                      | 正常情况不需要使用，可以利用它清除 frp，从而解除谷歌锁                                            |
| 恢复出厂                        | 我们选择点开下拉菜单后看到的"common1"，它会让设备重启到 Recovery 模式，并让用户手动完成擦除/data 的过程         |
| 重启功能                        | "到 9008"一项似乎无法正确工作                                                       |
| 其他                          | 均为顾名思义的内容，其中"切换槽位"一项似乎无法正常工作                                             |

（2）如果你坚持使用此工具，建议先回读分区表，本工具的刷入分区功能需要你手动输入分区名。
